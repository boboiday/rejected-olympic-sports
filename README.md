An entry for the make.fun bounty "Rejected Olympic Sports": one invented Olympic sport, submitted as a single funny line.

## The sport

Synchronised Napping: two athletes must fall asleep at the same instant, snore in perfect harmony with the national anthem, and wake up before the judges do — "10.0, and he's still dreaming."

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and prints it to stdout.
